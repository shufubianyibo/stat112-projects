# STAT/COMP 112 — Data Analysis

R and Quarto coursework, visualizations, and collaborative Olympic data analysis.

Coursework portfolio of **Han Sun ([shufubianyibo](https://github.com/shufubianyibo))**. This repository collects source snapshots from local projects so they can be browsed directly from my personal GitHub profile.

## Main project

### [Olympidata: exploring Olympic medal patterns](project-olympidata/)

A collaborative R/Quarto report exploring athlete characteristics and medal outcomes across several Olympic sports. The project combines a shared proposal, sport-specific analyses, visualizations, and a combined report. The team includes Avery Sheindlin, Jack Fang, Han Sun, and Khaleesi Chen, with original credits retained in the source.

Han's contribution is the [shooting and rowing analysis](project-olympidata/Shooting-Rowing-HanSun.qmd). Start there for the sport-specific data work, then read the [combined report source](project-olympidata/report.qmd) and [proposal](project-olympidata/proposal.qmd) for the wider team study. The analyses explore associations in observed data rather than establish causal effects on athletic success.
